- Preserva framework, package manager, lockfile y versiones compatibles de Verve. Base prevista: Next.js App Router, React y TypeScript. No fuerces una actualización mayor si rompe el template.

- Implementa los contratos del futuro runtime Eve mediante una interfaz propia de AgeOS; esta etapa usa ScriptedAssistantDriver y no necesita Eve, AI SDK, Gateway ni Sandbox activos.
- Si están disponibles, aplica vercel-react-best-practices al implementar React/Next.js y web-design-guidelines al revisar la UI. El MCP de ReUI y la API instalada gobiernan componentes y composición.
