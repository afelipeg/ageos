# Changelog

All notable changes to this template are documented in this file.

## 1.1.0 - 2026-08-06

- The data grid runs on TanStack Table v9: `useTable` with the primitive's
  `dataGridFeatures` bundle, columns typed `ColumnDef<DataGridFeatures, TRow>`,
  and `start`/`end` column pinning in place of `left`/`right`.
- Next.js 16.2.12, React 19.2.8 and Tailwind CSS 4.3.3.

## 1.0.0 - 2026-08-06

Initial release.
